# Library Visual Assets

- `library-play.svg`: original game and subject illustrations created for this project.
- `icons/*.svg`: unchanged Lucide icons from the pinned `lucide-static` development dependency. License in `icons/LICENSE`.
- `fonts/nunito-latin-wght-normal.woff2`: Nunito variable font from the pinned `@fontsource-variable/nunito` development dependency. SIL Open Font License in `fonts/LICENSE`.

The font and icons are copied into the repository so the isolated release never contacts a font or icon CDN. Their licenses are included in the public artifact. This font subset supports the current English interface; it does not imply translated content or international release approval.
